# Odovi 0.5.0 source candidate

Release version: `0.5.0`

This candidate adds three archive-based energy features:

- **Battery range history:** monthly post-charge rated-range medians and their
  change from the first month with usable range observations, with measurement coverage.
- **Charging economics:** energy losses, weighted charging efficiency, and
  matched costs by currency, charger type and location.
- **Since the last charge:** dashboard driving totals with explicit estimates,
  missing data and charging boundaries.

See [Battery and charging analytics](../energy-analytics.md) for the calculations
and their limits. English and German are supported throughout.

## Supported runtime

- Application: Node.js 22 in container images.
- Database: PostgreSQL 17.
- Orchestration: Docker Engine with Docker Compose v2.
- TeslaMate compatibility boundary: 4.0.1 through 4.2.0.
- Intended image platforms: `linux/amd64` and `linux/arm64`.

## Tested platforms

This is a local source candidate. Validation results are recorded after source,
database and browser checks. No published 0.5.0 image is implied by this document.
The immutable Compose template requires digests from an accepted candidate;
there are no default image digests for this version.

## Upgrade and recovery

Back up the Odovi database with the existing
[upgrade procedure](../upgrade-odovi.md) before deploying a candidate.
Migration `0011_battery_rated_range` adds one nullable charging field and resets
the TeslaMate charging watermark so historical range is read on the next sync.
The source TeslaMate database remains read-only.

Existing notes, prices, classifications and locked places are preserved.
Restoring the pre-upgrade backup remains the rollback path; use the matching
previous application version after restoring it.

## Known limitations

- Source candidate only: Git publication, container publication and deployment
  are separate release actions. Stable installation instructions remain on 0.4.0.
- Native Raspberry Pi, `linux/amd64`, multi-architecture images and upgrade
  acceptance against exact published images remain gates for stable promotion.
- Battery range is a BMS estimate relative to recorded history, not a factory
  health score, diagnosis or verified capacity measurement.
- Imports without independent rated-range measurements have no battery trend.
- Missing energy pairs and prices reduce the coverage of efficiency and cost
  calculations; unknown currencies are never inferred.
