# Tripatlas licensing

This document explains which terms apply to which parts and versions of
Tripatlas. If this summary and a license text differ, the license text controls.

## Current development versions

New Tripatlas versions first made available from the `0.2.x` licensing change
onward are available under the
[Functional Source License 1.1 with Apache-2.0 Future License](LICENSE)
(`FSL-1.1-ALv2`), unless a file or directory contains a more specific notice.

In practical terms, the license permits source inspection, self-hosting,
modification and redistribution for non-competing purposes. It does not permit
making Tripatlas, or substantially similar functionality, available to others
as a competing commercial product or service. Each version automatically also
becomes available under Apache-2.0 two years after that version was first made
available.

FSL is a Fair Source / source-available license. It is not an OSI-approved Open
Source license.

## Historical releases

Tripatlas `v0.1.0`, `v0.1.1` and public repository commits or feature branches
made available with the former AGPL-3.0 license remain available under
AGPL-3.0 for copies received under those terms. The later license change does
not revoke those rights. The applicable historical license is included in the
corresponding Git history, for example in
[`v0.1.1`](https://github.com/jsc2304/tripatlas/blob/v0.1.1/LICENSE).

In other words, the licensing change protects new versions and future work; it
cannot make code that was already published under AGPL proprietary or withdraw
the permissions already granted for that code.

## Excluded material

The marketing site in [`apps/marketing`](apps/marketing) has its own
proprietary license. Logos, brand assets and the Tripatlas name are not licensed
under FSL; see [TRADEMARKS.md](TRADEMARKS.md).

Third-party libraries and assets remain under their respective licenses. See
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for important notes.

## Commercial licensing

Uses that fall outside FSL can be permitted under a separate written commercial
license from the copyright holder. No permission is granted merely by asking
for or negotiating such a license.
